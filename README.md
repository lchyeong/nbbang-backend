# 계정 공유 서비스 N/BBANG

## 소개

### 기술 스택

## 기술 스택
- **Backend**: Java, Spring Boot, MySQL, H2
- **Frontend**: React, Zustand, Axios, Tailwind CSS, MUI
- **Deployment**: AWS EC2, RDS, Docker, Nginx, GitHub Actions

## 멤버



|   재형   |   찬형   |   현필   |   가은   |   동원   |    고은    |
|:-------:|:-------:|:-------:|:-------:|:-------:|:---------:|
| 매칭 기능 | 결제 기능 | 결제 기능 | 유저 기능 | 유저 기능 | 채팅, 알림 |


## 주요 기능
- **유저 기능**: 소셜 로그인, 메일 인증, 휴대폰 인증
- **매칭 기능**: 파티 생성 및 가입, 파티 탈퇴, 매칭 우선순위 적용
- **결제 기능**: 부트페이/카카오페이 정기결제, 부분취소 및 환불, 파티장 계좌 정산 시스템
- **채팅 기능**: 관리자와의 1:1 상담, 채팅 아카이브 저장
- **알림 기능**: SMS(Cool SMS), Email(Java Mail Sender, Google SMTP) 알림
